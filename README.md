# 🌿 웰컴 (Well, come)
> **"당신의 일상에 쉼표를, 웰니스 여행의 시작"**

'웰컴(Well, come)'은 일상 속 휴식이 필요한 현대인들을 위해 강원도의 웰니스 여행지를 시군별/테마별로 한눈에 확인하고 여행 계획을 세울 수 있는 서비스입니다. 한국관광공사의 데이터를 기반으로 신뢰도 높은 힐링 스팟 정보를 제공합니다.

** 현재 서버 비용 문제로 인해 앱 서비스 이용은 중단된 상태입니다.

## 🛠 유지보수 및 리팩토링
공모전 수상 이후, 서비스의 안정성과 데이터 정확도를 높이기 위해 다음과 같은 기술적 개선 과정을 거쳤습니다.

- 안정성 강화: 단위 테스트 코드를 추가하여 주요 기능의 무결성을 검증했습니다. 
- 데이터 최신화: 한국관광공사 TourAPI의 최신 업데이트 버전을 반영하여 데이터 동기화 로직을 개선하고 정보의 정확도를 높였습니다.
- 코드 품질 개선: 가독성과 유지보수 용이성을 위해 전반적인 코드 리팩토링을 진행하여 더 견고한 소프트웨어 구조를 확보했습니다.
